# Wireshark and Network Traffic Investigation 🌐🔍

## Welcome to My Wireshark Adventure! 🚀

In this project, I explored the world of network traffic analysis using **Wireshark** and the `ping` utility. This assignment was all about understanding how devices communicate over a network, capturing packets, and analyzing their details to uncover valuable insights. If you’re curious about how data travels across networks or want to learn more about tools like Wireshark, this guide will walk you through my journey step-by-step.

---

## What Was I Doing? 🤔

This assignment focused on two main tasks:
1. **Using `ping` to Test Network Connectivity**:
   - Sent ICMP (Internet Control Message Protocol) requests to URLs like `www.yahoo.com`, `www.cisco.com`, and `www.google.com`.
   - Discovered their IP addresses and learned how ICMP helps diagnose network issues.
2. **Capturing and Analyzing Traffic with Wireshark**:
   - Used Wireshark to capture packet data and analyze it in detail.
   - Explored MAC and IP addresses, protocols, and communication patterns.
   - Created and managed firewall rules to allow or block ICMP traffic.

Through hands-on exercises, I gained practical experience in network enumeration, packet analysis, and firewall configuration.

---

## Tools Used 🔧

1. **Wireshark**: A powerful tool for capturing and dissecting network traffic at various layers.
2. **Ping Utility**: Tested connectivity and resolved domain names into IP addresses.
3. **Windows Defender Firewall**:
   - Created inbound rules to allow ICMP traffic.
   - Disabled or deleted rules as needed for testing purposes.
4. **Command Line**: Used commands like `ping` to interact with networked devices.

---

## Skills Gained 💡

- **Network Enumeration**:
  - Resolved domain names (e.g., `www.google.com`) into IP addresses using `ping`.
  - Identified MAC addresses of local devices and routers.
- **Packet Analysis**:
  - Captured and analyzed network traffic using Wireshark.
  - Examined details like source/destination MAC/IP addresses and protocol types.
- **Firewall Management**:
  - Created custom inbound rules to allow ICMP traffic.
  - Disabled or deleted rules for testing and troubleshooting.
- **Understanding Protocols**:
  - Learned about ICMP and its role in diagnosing network issues.
  - Explored how MAC addresses operate within local networks.
- **Reflection and Problem-Solving**:
  - Answered critical questions about why Wireshark shows local MAC addresses but not remote ones.
  - Analyzed differences between local and remote traffic information.

---

## Fun Highlights 🎉

- **"Ping Power"**: Used `ping` to resolve URLs into IP addresses—turning human-readable names into machine-friendly numbers.
- **"MAC Address Mystery"**: Discovered why Wireshark only shows MAC addresses for local devices (spoiler: MAC addresses don’t travel beyond the local network).
- **"Firewall Wizardry"**: Created an inbound rule to allow ICMP traffic, then disabled it to test firewall management skills.
- **"Packet Detective"**: Analyzed captured packets to uncover details like TTL (Time to Live) and protocol types.
- **"Remote vs. Local"**: Reflected on why Wireshark provides detailed information for local hosts but limited data for remote ones.
